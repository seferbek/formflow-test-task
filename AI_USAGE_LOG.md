# Лог использования AI

Проект создан совместно с AI-ассистентом в рамках требования тестового задания.

| Этап | Как использовался AI | Результат |
|---|---|---|
| Декомпозиция | Помощь в выборе реалистичного MVP и модели данных | Выбраны Express и локальный JSON без внешних сервисов |
| Реализация | Генерация стартовой структуры, API и интерфейса | Админка, публичные формы, ответы и аналитика |
| Проверка | Подсказки для smoke-тестов и проверки сценария | Проверены запуск и ключевые HTTP-сценарии |
| Документация | Формулировка README и ограничений MVP | Инструкция запуска и честное описание возможностей |

Человек проверяет результат, запускает проект локально и принимает решения о публикации.
