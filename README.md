# FormFlow — сервис форм отклика

Небольшой автономный MVP для тестового задания: менеджер создаёт форму, публикует уникальную ссылку, студент заполняет анкету, а менеджер смотрит ответы и простую воронку.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

Откройте [http://localhost:3000/admin](http://localhost:3000/admin). По умолчанию сервис работает на порту 3000. Другой порт: `PORT=4000 npm start`.

## Что реализовано

- Админка без авторизации на `/admin`.
- Создание, редактирование и сохранение черновиков.
- Типы вопросов: короткий текст, email, развёрнутый текст, список, один или несколько вариантов; обязательность вопроса.
- Публикация с уникальной стабильной ссылкой `/f/<slug>` и копирование ссылки.
- Проверка обязательных полей и email на стороне сервера.
- Просмотр всех ответов в админке.
- Честная базовая аналитика: уникальные просмотры, начала заполнения, отправки и доля завершивших среди начавших. Для новых сессий также видно, до какого вопроса дошли участники.
- Локальные данные в `data/db.json`, который создаётся автоматически при первом изменении. Удалите этот файл, чтобы начать с чистой базы.

## Дизайн и работа с низкой конверсией

Публичная анкета намеренно устроена не как длинный список полей, а как короткий пошаговый сценарий:

- Перед началом студент видит количество вопросов и ориентировочное время заполнения.
- На экране только один вопрос: это снижает ощущение объёма работы и помогает сфокусироваться.
- Прогресс-бар и счётчик вопросов показывают, сколько уже пройдено и сколько осталось.
- Все промежуточные ответы автоматически сохраняются в браузере. Если закрыть вкладку, можно продолжить с прежнего места.
- Необязательные вопросы явно отмечены, а ошибки показываются рядом с текущим вопросом.
- Крупные элементы управления и адаптивная вёрстка рассчитаны в том числе на мобильный экран.

В админке у опубликованной формы доступны воронка «просмотр → начало → отправка» и путь по вопросам. Это позволяет увидеть точку, где участники прекращают заполнение, после чего менеджер может упростить формулировку, переставить вопрос или сделать его необязательным.

> Примечание: путь по вопросам собирается для событий, записанных после обновления приложения. Старые записи не ломают экран статистики, но могут не содержать этих данных.

## Архитектура

Express обслуживает статические страницы и небольшой JSON API. Все записи читаются и сохраняются в одном JSON-файле; это осознанный выбор для автономного тестового MVP без внешней базы данных. Проект не требует API-ключей, облачных сервисов или отдельной СУБД.

## Проверка сценария

1. В `/admin` нажмите «Создать форму», измените название и вопросы, затем «Опубликовать».
2. Скопируйте ссылку и откройте её в отдельном/инкогнито-окне.
3. Заполните и отправьте анкету.
4. Вернитесь в админку: ответ и метрики появятся в разделе «Ответы и конверсия».

### Проверка сохранения черновика

1. Откройте опубликованную ссылку и начните отвечать.
2. Введите ответ и закройте вкладку до отправки.
3. Откройте эту же ссылку в том же браузере: кнопка предложит продолжить заполнение.

### Что означают метрики

- **Просмотры** — уникальные браузерные сессии, открывшие форму.
- **Начали** — сессии, в которых пользователь начал вводить или выбирать ответ.
- **Отправили** — сессии с успешно сохранённой анкетой.
- **Завершили из начавших** — отношение отправивших к начавшим; это честнее, чем делить на все просмотры.
- **Где продолжают заполнять** — сколько начавших сессий сфокусировалось на каждом вопросе.

## Ограничения MVP

Это не production-сервис: нет учётных записей, экспорта, защиты от повторных ответов или конкурентной блокировки JSON-файла. Эти улучшения намеренно оставлены вне двухчасового объёма задания.
